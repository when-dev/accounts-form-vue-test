# Accounts Form (Vue 3)

Тестовое задание: реализация формы управления учетными записями с помощью Vue 3.

Требуемый функционал:

- Добавлять учетные записи
- Удалять учетные записи
- Редактировать поля учетных записей
- Выполнять валидацию данных при вводе
- Сохранять данные при обновлении страницы

---

## Стек технологий

- Vue 3 (Composition API)
- TypeScript
- Pinia
- Element Plus
- Vite

---

## Установка

```bash
npm install
npm run dev
```
