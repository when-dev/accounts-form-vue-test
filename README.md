# Accounts Form (Vue 3)

Тестовое задание: реализация формы управления учетными записями с помощью Vue 3.

---

## Функциональность

- Добавление/удаление учетных записей
- Редактирование полей учетных записей
- Поддержка типов записи:
	- **LOCAL** (Локальный) - пароль обязателен
	- **LDAP** - пароль скрывается и сохраняется как `null`
- Валидация полей:
	- Выполняется при потере фокуса (blur) для input 
	- Выполняется при изменении значения (change) для select
- Поле "Метки":
	- Ввод через `;`
	- Сохраняется как массив объектов `{ text: string }`
- Сохранение данных в `localStorage`
	- Ключ: `accounts-form-data`
	- Данные сохраняются между перезагрузками страницы
